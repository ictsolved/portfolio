Learning Management System (QubexEdu LMS)

2018-2019
Professional Flutter

Different mobile applications of learning management system for students, teachers and parents.

QubexEdu LMS is a learning management system with dedicated Flutter mobile apps for three user roles: students, teachers, and parents. Each app provides role-appropriate access to coursework, assignments, attendance records, and school communications.

Built during an internship at Qubex Edu ERP, the project involved developing the Flutter client apps alongside a .NET Core REST API and a Vue.js admin dashboard.
