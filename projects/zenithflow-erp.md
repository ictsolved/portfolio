ZenithFlow is a full-featured Enterprise Resource Planning system built for mid-to-large organizations. The mobile client is built with Flutter, the backend with Laravel, and data is persisted in PostgreSQL.

Key integration: ZK biometric devices are connected directly to the system for real-time attendance tracking and access control — eliminating manual entry and enabling automated payroll calculations.
