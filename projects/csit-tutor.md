CSIT Tutor is a free study platform for students enrolled in the B.Sc. CSIT program at Tribhuvan University, Nepal. It provides complete reference materials, semester-wise syllabi, past questions, notices, and preparation resources — all in one place.

The platform has a web version built with Jekyll and a companion Android app built with Flutter, backed by a Node.js API. It has been actively maintained since 2020 and continues to serve thousands of students each semester.
